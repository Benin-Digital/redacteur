Mot de passe d'application WordPress

Connectez votre site WordPress à l'agent IA de rédaction web en toute sécurité

Qu'est-ce qu'un mot de passe d'application ?

Un mot de passe d'application est un code unique généré par WordPress qui permet à des applications tierces (comme notre agent IA de rédaction web) de communiquer avec votre site sans utiliser votre mot de passe principal.

Cette technologie, introduite par WordPress, offre une couche de sécurité supplémentaire en vous permettant de :

  • Générer des mots de passe spécifiques par application
  • Révoquer l'accès à tout moment sans changer votre mot de passe principal
  • Limiter les risques en cas de fuite de données

Pourquoi est-ce nécessaire pour notre agent IA ?

Notre agent IA de rédaction web a besoin d'une connexion sécurisée à votre site WordPress pour :

Publication automatique

Publiez instantanément les articles générés par l'IA sur votre site

Programmation

Planifiez vos articles pour une publication ultérieure

Gestion des catégories

Créez et assignez automatiquement des catégories et tags

SEO optimisé

Structurez vos articles avec les bonnes métadonnées SEO

Une sécurité renforcée

Pas de partage de mot de passe

Votre mot de passe principal reste confidentiel. Le mot de passe d'application est révocable indépendamment.

Contrôle total

Générez, révoquez et gérez chaque mot de passe d'application depuis votre profil WordPress.

Chiffrement des données

Tous les mots de passe d'application sont chiffrés dans notre base de données.

Notre plateforme est conforme aux standards de sécurité les plus stricts

Comment générer votre mot de passe d'application

1

Connectez-vous à votre administration WordPress

Rendez-vous sur https://votre-site.com/wp-admin et connectez-vous avec vos identifiants administrateur.

2

Accédez à votre profil utilisateur

Dans le menu latéral gauche, cliquez sur Utilisateurs → Votre profil.

3

Créez un mot de passe d'application

Scrollez jusqu'à la section Mots de passe d'application. Saisissez un nom (ex: "Agent IA Rédaction") et cliquez sur Ajouter un nouveau mot de passe d'application.

4

Copiez le mot de passe généré

Un code au format xxxx xxxx xxxx xxxx apparaît. Copiez-le immédiatement — il ne sera plus affiché après avoir quitté la page.

Ce mot de passe ne vous sera plus jamais affiché. Conservez-le précieusement !
5

Configurez dans notre plateforme

Revenez sur notre plateforme et renseignez :

  • L'URL de votre site WordPress
  • Votre nom d'utilisateur WordPress
  • Le mot de passe d'application généré

L'API REST WordPress : Le pont sécurisé

Notre agent IA utilise l'API REST de WordPress — une interface de communication standard qui permet aux applications externes d'interagir avec votre site.

POST /wp-json/wp/v2/posts → Publication d'un article
GET /wp-json/wp/v2/users/me → Vérification de l'authentification
POST /wp-json/wp/v2/categories → Création de catégories

Toutes les communications sont effectuées en HTTPS (si configuré sur votre site) et authentifiées via le mot de passe d'application.

Questions fréquentes

Que faire si j'ai perdu mon mot de passe d'application ?

Rendez-vous dans votre profil WordPress, révoquez l'ancien mot de passe et générez-en un nouveau. Puis mettez à jour la configuration dans notre plateforme.

Puis-je utiliser plusieurs mots de passe pour différentes applications ?

Absolument ! WordPress vous permet de générer plusieurs mots de passe d'application, un par application tierce.

Comment révoquer l'accès de l'agent IA ?

Dans votre profil WordPress, cliquez sur Révoquer à côté du mot de passe d'application correspondant. L'accès sera immédiatement bloqué.

Est-ce que mon mot de passe principal est en danger ?

Non. Le mot de passe d'application est indépendant. En cas de compromission, vous pouvez le révoquer sans modifier votre mot de passe principal.

Le mot de passe d'application WordPress est la méthode la plus sécurisée pour connecter notre agent IA à votre site. Il vous offre un contrôle total sur les accès tout en protégeant vos identifiants principaux.
